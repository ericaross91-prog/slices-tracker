⚙ Connect Google Sheets — Full Setup Guide

STEP 1 — Create a Google Sheet
Go to sheets.google.com and create a new blank spreadsheet. Name it something like SLICES Tracker Data. Leave it open.

STEP 2 — Open Apps Script
In your Google Sheet, click the menu:
Extensions → Apps Script
A new browser tab will open with the script editor.

STEP 3 — Paste this code
Delete everything in the editor, then paste the entire block below:

Apps Script code to paste:
const SHEET_NAME = 'TrackerData'; // ── doPost: receives JSON body from tracker ── // The tracker sends JSON via fetch with Content-Type application/json. // Apps Script receives this in e.postData.contents. function doPost(e) { try { const raw = e.postData && e.postData.contents ? e.postData.contents : (e.parameter && e.parameter.payload ? e.parameter.payload : '{}'); const data = JSON.parse(raw); const ss = SpreadsheetApp.getActiveSpreadsheet(); let sheet = ss.getSheetByName(SHEET_NAME); if (!sheet) sheet = ss.insertSheet(SHEET_NAME); if (data.action === 'write' && data.rows) { sheet.clearContents(); const headers = ['id','business','businessType','address','zip','phone', 'email','contact','title','mode','initDate','lastDate', 'sessionConfirmed','dateTime','volunteer','notes','targetLocation','target','version']; sheet.appendRow(headers); const ver = data.version || Date.now(); data.rows.forEach(r => { sheet.appendRow([ r.id, r.business, r.businessType||'', r.address, r.zip, r.phone, r.email, r.contact, r.title, r.mode, r.initDate, r.lastDate, r.sessionConfirmed, r.dateTime, r.volunteer, r.notes, r.targetLocation||'', data.target||21, ver ]); }); } return ContentService .createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({status:'error',msg:err.message})) .setMimeType(ContentService.MimeType.JSON); } } // ── doGet: returns data as JSONP so local HTML files can read it ── // The tracker requests: ?action=read&callback=_slicesCallback_123 // We wrap the response: _slicesCallback_123({rows:[...], target:21}) function doGet(e) { const callback = e.parameter.callback || 'callback'; try { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sheet = ss.getSheetByName(SHEET_NAME); if (!sheet || sheet.getLastRow() < 2) { return ContentService .createTextOutput(callback + '(' + JSON.stringify({rows:[],target:21}) + ')') .setMimeType(ContentService.MimeType.JAVASCRIPT); } const data = sheet.getDataRange().getValues(); const headers = data[0]; const rows = data.slice(1).map(row => { const obj = {}; headers.forEach((h,i) => { obj[h] = (row[i] === null || row[i] === undefined) ? '' : String(row[i]); }); return obj; }); const target = rows.length ? (parseInt(rows[0].target) || 21) : 21; const version = rows.length ? (parseInt(rows[0].version) || 0) : 0; rows.forEach(r => { delete r.target; delete r.version; }); return ContentService .createTextOutput(callback + '(' + JSON.stringify({rows, target, version}) + ')') .setMimeType(ContentService.MimeType.JAVASCRIPT); } catch(err) { return ContentService .createTextOutput(callback + '(' + JSON.stringify({rows:[],target:21,error:err.message}) + ')') .setMimeType(ContentService.MimeType.JAVASCRIPT); } }

STEP 4 — Save the script
Click the 💾 Save icon (or press Ctrl+S / Cmd+S). Name the project anything you like, e.g. SLICES Sync.

STEP 5 — Deploy as a Web App
Click Deploy → New deployment
Click the ⚙ gear icon next to "Select type" and choose Web app.
Set these two fields:
  • Execute as: Me (your Google account)
  • Who has access: Anyone
Click Deploy. If prompted, click Authorize access and sign in with your Google account.

STEP 6 — Copy the Deployment URL
After deploying, Google shows a Web app URL that looks like:
https://script.google.com/macros/s/AKfy.../exec
Copy that entire URL and paste it in the box below.

STEP 7 — Share this HTML file
Save the tracker HTML file to a shared location (Google Drive, shared folder, or a simple web host). Every team member opens the same HTML file and connects using the same Deployment URL. All edits sync every 30 seconds across all users.
⚠ Troubleshooting "Pull failed / Failed to fetch"
This error means the tracker cannot reach Google Sheets. Common causes:
 • The Deployment URL is missing or incorrect in the file
 • The Apps Script was not deployed with Who has access: Anyone
 • You redeployed and got a new URL — must re-paste the new URL
 • The HTML file is open directly from Google Drive preview — download it and open in Chrome instead
 • Your browser is blocking cross-origin requests — try Chrome or Edge

Once connected, every edit pushes to your Google Sheet instantly and all users pull the latest data every 30 seconds automatically.
